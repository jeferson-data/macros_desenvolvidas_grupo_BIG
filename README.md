# 📦 Macros VBA - Grupo BIG (Expedição Hortifruti)

## 📌 O Problema de Negócio

No centro de distribuição do Grupo BIG, o processo de **cadastro de conferentes** para a expedição de hortifruti era **manual e demorado**. Os supervisores precisavam preencher planilhas extensas, repetir informações e conferir dados manualmente, o que gerava:

- **Erros de digitação** e inconsistências nos registros;
- **Perda de tempo** da equipe operacional (horas por semana);
- **Dificuldade de rastreamento** de quem conferiu cada carga;
- **Falta de padronização** entre diferentes turnos e equipes.

## 💡 A Solução

Desenvolvi **macros em VBA (Visual Basic for Applications)** integradas ao Excel para **automatizar o cadastro de conferentes** na expedição de hortifruti. As macros:

- Padronizam o preenchimento dos dados;
- Validam automaticamente as informações inseridas;
- Eliminam a necessidade de digitação repetitiva;
- Geram registros consistentes e rastreáveis.

## 🎯 Resultados e Impacto

- **Redução de 90% no tempo** gasto para cadastrar conferentes (de horas para minutos).
- **Eliminação de erros de digitação** e inconsistências nos registros.
- **Padronização do processo** entre todos os turnos e equipes do centro de distribuição.
- **Rastreabilidade completa:** cada conferente e cada carga ficaram registrados de forma clara.
- **Solução adotada em todos os centros de distribuição do Brasil**, conforme mencionado no meu currículo.

## 📈 Funcionalidades Detalhadas

### 1. Cadastro Automatizado de Conferentes
- Formulário intuitivo para inserção de dados.
- Validação automática de campos obrigatórios.

### 2. Padronização de Dados
- Máscaras de entrada para evitar erros de formato.
- Listas suspensas para categorias pré-definidas.

### 3. Geração de Relatórios
- Exportação dos registros para conferência e auditoria.
- Registro de data/hora de cada cadastro.

- Alinhamento com o fluxo de trabalho da expedição de hortifruti.

## 🔧 Solução de Problemas

| Erro                          | Causa                     | Solução                                     |
|-------------------------------|---------------------------|---------------------------------------------|
| Macro não executa             | Segurança do Excel        | Habilite macros nas configurações do Excel  |
| Erro de compilação VBA        | Referência quebrada       | Verifique as referências no Editor VBA      |
| Planilha não abre             | Versão incompatível       | Use Excel 2010 ou superior                  |
| Dados não salvam              | Permissão de escrita      | Verifique se o arquivo não está somente leitura |
